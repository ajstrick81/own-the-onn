# 09 — Experiments

Hypotheses, procedures, and results. One file per experiment
(`AML-E####`), using `../_templates/experiment.md`.

- Favor **read-only** experiments, especially early.
- Record the **actual** observations, including unsuccessful ones — a failed
  experiment that tells us precisely which assumption was wrong is a result.
- Device-touching vs. emulator/sandbox must be explicit in the procedure.
- Artifacts list filenames/paths of logs and images, never raw PII, captures,
  or firmware (those are git-ignored).
