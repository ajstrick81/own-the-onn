# 00 — Project Management

Objectives, roadmap, decisions, and progress for the Amlogic architecture
knowledge base (Onn as primary experimental target).

- `roadmap.md` — the current phase plan and completion criteria.
- `decisions/` — decision records (`AML-D####`), one file each, from the
  `../_templates/decision.md` template.

A decision record captures *why* a direction was chosen so a later reader
(or a later us) doesn't relitigate it without new evidence.
