# AML-S0001 — onn 4K Plus (coffey) on-device identification

## What it is
Direct on-device readout of the owner's own onn 4K Plus ("coffey"): Android
`getprop` build properties and the kernel's own `/proc/config.gz`, read over
adb on hardware we own.

## What it establishes
The device's identity as settled against primary sources on the device
itself: SoC line, kernel version/arch, Android version, security patch level,
and bootloader lock state. These back the `AML-F0001` device-inventory record
at `exact-device` scope.

## Credibility note
`primary` — the values come from the device's own build properties and kernel
config, not from a spec sheet, retail listing, or aggregator. Published
summary of the same facts appears in `../../../research/root-study.md`.
