# AML-S0007 — coffey on-device read-only partition enumeration

## What it is
Direct, read-only observation of the running coffey device (Walmart onn 4K Plus,
onn/coffey URO4.260304.011.B1, slot `_b`) over `adb shell` as the unprivileged
`shell` user (uid 2000, `u:r:shell:s0`). Commands: `lpdump` (logical/super
metadata), `ls -l /dev/block/by-name/` (physical partition map), `getprop`
(build/slot/bootloader). No root, no modification, no flashing. Raw captures in
`E:\Morphe\device\coffey-ota\analysis\` (lpdump-coffey-slot_b.txt, by-name.txt,
proc-partitions.txt, sysfs-mmc-geometry.txt).

## What it establishes
The authoritative, device-confirmed logical (super) partition metadata and the
physical partition name→block-device map for coffey's active slot, backing
`AML-F0008`. Build fingerprint confirms this is exactly the OTA build analyzed
offline (URO4.260304.011.B1 / slot `_b`), tying the device state to AML-S0005.

## Credibility note
`primary` — a reproducible first-hand observation of the actual device. Scope
`exact-device`: read from the running coffey unit itself. Note the ceiling:
`lpdump` (super metadata) is readable by the `shell` user, but raw sysfs block
geometry (`/sys/block/mmcblk0/*/start`, `/proc/partitions`) and raw-disk GPT
reads are **SELinux-denied without root** — so absolute GPT start-LBAs are not
obtainable on this device by this method.
