# AML-S0002 — CoreELEC common_drivers 5.15 kernel source tree

## What it is
Open-source Amlogic 5.15 kernel sources (CoreELEC `common_drivers` lineage)
used as the buildable stand-in for the device kernel line in the QEMU
sandbox.

## What it establishes
Source-level behavior of kernel subsystems at the 5.15 Amlogic line, and a
buildable kernel for emulator-only reproduction work.

## Credibility note
`primary` for the CoreELEC tree's own source. **Scope is `related-family`, not
`exact-device`:** this is NOT coffey's exact signed vendor kernel. Any claim
that a sandbox result applies to coffey must be qualified until
production-source equivalence (same subsystem source + config) is established
against coffey's own build. Conflating "built from this tree" with "coffey
behaves this way" is exactly the upgrade this KB forbids.
