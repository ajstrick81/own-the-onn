# AML-S0010 — Khadas Amlogic vendor-common systemcontrol/PQ reference source

## What it is
The public Khadas Android 14 `vendor/amlogic/common` tree, pinned at commit
`992853c992d9206c3c0aedbb44415b0777155661`. Used as the *interface-shape*
reference for coffey's shipped `vendor/bin/systemcontrol` (stripped) and
`vendor/lib/libpqcontrol.so`: the service's `permissionCheck()`, the generated
HIDL read/write wrappers in `SystemControlHal.cpp`, and the PQ database path
selection in `PQ/utils/CConfigFile.cpp`.

## Scope / caveat
`related-family`: this is Khadas's build of the Amlogic vendor-common tree, not
coffey's exact vendor source. It establishes expected structure and symbol
correspondence only — it does **not** establish byte-exact equivalence with the
shipped coffey binaries. Device-scope claims must rest on the shipped artifacts
(AML-S0005), with this source as corroborating context.
