# 11 — Verified Findings

Promoted conclusions: findings that have been reviewed and whose confidence
and scope are settled. One file per finding (`AML-F####`), using
`../_templates/finding.md`, with `status: promoted`.

This section is the project's durable output. A finding reaches here only
after its evidence, alternative explanations, and scope have been checked —
never by silently upgrading a draft. Drafts and in-progress findings live in
the relevant topic section (03–08) until promoted.
