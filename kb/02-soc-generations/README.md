# 02 — SoC Generations

The Amlogic family tree and cross-generation architecture comparisons. This
is where the project's core theory lives: *generations inherit architectural
DNA, but similarity is not binary or security-behavior equivalence.*

- `compatibility-matrix.md` — the working matrices (seeded from
  `../_templates/compatibility-matrix.md`). One matrix per question, every
  cell confidence-tagged.

A difference between generations is a finding (`AML-F####`), not just a table
cell — record it in `11-verified-findings/` and cite it in the matrix.
