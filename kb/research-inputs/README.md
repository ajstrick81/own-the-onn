# research-inputs — raw material, NOT evidence

Original research notes and inputs (e.g. `S7DResearch.txt`, dumps of prior
investigations) are preserved here **separately from validated conclusions**.

Nothing in this folder is automatically a finding. Where a note cites source
code, documentation, or an experiment, trace it back to the original source
and register that source (`AML-S####` in `../10-source-library/`) before
promoting a claim into a `confirmed` finding in `../11-verified-findings/`.

Do not commit personal data, vendor code, or firmware images here — the repo
`.gitignore` blocks raw captures/dumps; keep raw inputs that contain
identifiers out of the repo entirely.
