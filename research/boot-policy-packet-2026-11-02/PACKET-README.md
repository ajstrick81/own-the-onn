# Coffey public-artifact research packet

Start with RELAY-SUMMARY.md, then the five COFFEY reports. Files under artifacts/ are public reference material; recovered executables/scripts are evidence, not instructions to run. No coffey device artifacts are included.

Two complete images are supplied separately as release.img.gz and nightly-new.img.gz. Their exact publisher names, URLs, sizes and SHA-256 are in COFFEY-PUBLIC-ARTIFACT-MANIFEST.md. The original November 2 nightly is not retained; its prior hash is historical only.

SHA256SUMS covers all files in this ZIP except itself. Validate after extraction. Source references and per-file provenance are in the manifest and JSON sidecars. Generated DTS files come from the shipped donor DTBs, not coffey. The host-side parsers are provided for review; no recovered firmware code was executed.
